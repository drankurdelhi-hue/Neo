Aaj ki NeoSapien memories ka digest WhatsApp self-chat me bhejo. Ye automated scheduled run hai - koi insaan intezaar nahi kar raha, to bina kuch poochhe kaam karo aur khatam karo.

STEP 1 - NeoSapien se aaj ka data lao:
`search_memories` call karo: start_date = aaj ki date "YYYY-MM-DDT00:00:00", end_date = aaj ki date "YYYY-MM-DDT23:59:59", limit 100, sort_by "created_at", sort_order "asc".
Response me `total_pages` dekho. Agar 1 se zyada hai to page=2, page=3 ... sab laao. Adhoore data pe digest mat banao.

STEP 2 - memory object ka shape:
Result `items` array me aata hai, aur har item ek wrapper hai: {"memory": {...}, "user": {...}}. To item["memory"] ke andar jao. Jo fields chahiye: title, summary, created_at, domains (array).
created_at me timezone offset hota hai (jaise "2026-09-13T12:03:17.536000+05:30") - usi local time ko use karo.

STEP 3 - digest banao. YE WHATSAPP MARKUP HAI, MARKDOWN NAHI:
- bold = *single asterisk*. Double asterisk kabhi nahi - wo WhatsApp me literally dikhta hai.
- italic = _underscore_
- Hash headers aur [text](url) kaam nahi karte. Raw URL likho.
- Em dash aur en dash kabhi mat likho. Normal hyphen (-) use karo.

Format (ye tested hai, isi ko follow karo):

Pehli line:
*Aaj ki Memories* - N memories (13 Sept)

Phir memories ko unke domains[0] ke hisaab se group karo. Jis domain me zyada memories hain wo pehle. Har group:

*Domain Name* (count)
- HH:MM chhota description, ek line me

Jis domain me sirf 1 memory hai, use alag group na banao - sabko aakhir me ek *Baaki* (count) group me daal do.

Har line ka description title aur summary se banao, ek line me, chhota aur scannable. Poora summary paste mat karo - wo bahut lamba ho jaata hai. Naam aur jagah jo summary me hain wo rakh lo, wahi kaam ki cheez hoti hai.

STEP 4 - Perisclaw se bhejo:
`message_send` call karo, chat_id = "self", text = digest.
Agar digest 4000 characters se lamba ho gaya to 4000-char tukdon me todo, har tukde ke aakhir me "(1/3)" style footer lagao, aur ek-ek karke bhejo. Compact format me aam taur pe ek hi message me aa jaata hai.

STEP 5 - agar aaj koi memory nahi mili:
Ye bhejo: "*Aaj ki Memories*" phir do newline phir "Aaj koi memory nahi mili."

Bas yahi karna hai. Koi file mat banao, koi code mat likho, koi repo mat chhedo, kisi aur chat me message mat bhejo.
